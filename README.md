# ConnectHub (PHP MVC)

A role-based social app built in plain PHP following MVC. This was my version before moving it to Laravel.

What it does:
- Three roles: admin, user, moderator
- Posts, friends, basic feed
- Login with sessions, MySQL backend

Stack: PHP, MySQL, HTML/CSS, no framework

Run it:
```bash
# import schema.sql + connecthub_full_database.sql to MySQL
# update config.php with your DB creds
php -S localhost:8000
```
